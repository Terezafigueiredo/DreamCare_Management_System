# DreamCare Management System

Sistema de gestão de sonhos de pacientes desenvolvido com Python, Tkinter e PostgreSQL, criado com foco em organização, automação e impacto social.

O projeto permite cadastrar, visualizar, editar, pesquisar e excluir registros de sonhos de pacientes em tratamento de saúde, oferecendo uma interface gráfica integrada a um banco de dados PostgreSQL.

Além do CRUD completo, o sistema também realiza integração com planilhas Excel, tratamento de dados e estruturação para futuras análises e dashboards.

## Funcionalidades

- Cadastro de pacientes e sonhos
- Listagem dinâmica em tabela
- Pesquisa por nome, hospital ou status
- Edição e exclusão de registros
- Integração com PostgreSQL
- Tratamento de dados com Python
- Interface gráfica com Tkinter
- Estrutura preparada para dashboards e automações

## Tecnologias utilizadas

- Python
- Tkinter
- PostgreSQL
- Pandas
- SQLAlchemy
- Psycopg2

## Objetivo

Criar uma plataforma de gestão de dados com propósito social, unindo desenvolvimento de software, banco de dados e engenharia de dados em um projeto real.

O projeto nasceu da necessidade de automatizar cadastros que antes eram feitos em planilhas Excel, tornando o processo mais organizado, seguro e escalável.
