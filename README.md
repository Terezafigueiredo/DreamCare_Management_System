# DreamCare Management System

Sistema completo de gestão de sonhos de pacientes desenvolvido com Python, Tkinter e PostgreSQL, criado com foco em organização, automação e impacto social.

O projeto permite cadastrar, visualizar, editar, pesquisar e excluir registros de sonhos de pacientes em tratamento de saúde, oferecendo uma interface intuitiva integrada a um banco de dados PostgreSQL.

Além do CRUD completo, o sistema também realiza integração com planilhas Excel, tratamento de dados e estruturação para futuras análises e dashboards.

## Funcionalidades

* Cadastro de pacientes e sonhos
* Listagem dinâmica em tabela
* Pesquisa por nome, hospital ou status
* Edição e exclusão de registros
* Integração com PostgreSQL
* Tratamento de dados com Python
* Interface gráfica com Tkinter
* Estrutura preparada para dashboards e automações

## Tecnologias utilizadas

* Python
* Tkinter
* PostgreSQL
* Pandas
* SQLAlchemy
* Psycopg2

## Objetivo

Criar uma plataforma de gestão de dados com propósito social, unindo desenvolvimento de software, banco de dados e engenharia de dados em um projeto real.

Projeto desenvolvido para estudo, atuo nesse instituto onde realizamos sonhos de pessoas em tratamento de doenças graves e resolvi desenvolver um projeto para automatizar os cadastros que eram feitos anteriormente em uma planilha do excel.
